# Футболки Russia — магазин футбольной атрибутики

Next.js 15 (App Router) + Tailwind CSS 4. Каталог с фильтром, корзина, оформление заказа.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

> Первый `npm install` тянет ~300 МБ, это нормально. Нужен Node.js 18.18 или новее — проверить: `node -v`

## Заказы на почту

Заказ уходит письмом через [Web3Forms](https://web3forms.com) — бесплатно, без регистрации.

1. Зайти на web3forms.com, ввести почту, получить access key письмом.
2. Создать файл `.env.local` в корне проекта:

```
WEB3FORMS_ACCESS_KEY=ваш-ключ
```

3. Перезапустить `npm run dev`.

Ключ публичный, это не пароль от почты — пароль нигде вводить не нужно.

Без ключа сайт работает: заказ пишется в логи сервера, а клиент всё равно видит телефон и может позвонить.

## Добавить товар

Открыть `lib/products.js`, дописать объект в массив `PRODUCTS`:

```js
{
  id: "unique-id",
  title: "Название",
  category: "clubs",      // clubs | national | retro | fan
  price: 4290,
  oldPrice: 5290,         // необязательно, показывается зачёркнутым
  badge: "Хит",           // необязательно
  image: "/products/файл.webp",
  sizes: ["S", "M", "L"],
}
```

Фото положить в `public/products/`.

## Заменить заглушки на реальные фото

Сейчас в каталоге SVG-заглушки. Когда будут снимки:

1. Сохранить в `public/products/` в WebP, пропорции 4:5, вес до ~200 КБ.
2. Прописать пути в `lib/products.js`.
3. В `components/ProductCard.jsx` заменить `<img>` на `next/image` — получится автоматическая оптимизация.

Фотографии в этой нише решают больше, чем дизайн. Снимать лучше на однотонном фоне при дневном свете, все товары одинаково.

## Деплой

1. Залить папку в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) нажать Add New → Project → импортировать репозиторий.
3. В Settings → Environment Variables добавить `WEB3FORMS_ACCESS_KEY`.

Домен вида `имя.vercel.app` и SSL дают бесплатно.

## Структура

```
app/
  layout.jsx          шрифты, метатеги, провайдер корзины
  page.jsx            сборка секций главной
  globals.css         дизайн-токены (цвета, шрифты)
  api/order/route.js  приём заказа и отправка на почту
components/           секции и UI
lib/
  products.js         каталог
  contacts.js         контакты
  cart-context.jsx    состояние корзины
public/products/      картинки товаров
```
