# Куда приходят заявки

## Как это устроено

Покупатель заполняет форму в корзине и нажимает «Оформить заказ». Дальше:

```
Браузер покупателя
        ↓
Твой сайт (файл app/api/order/route.js)
        ↓
   ┌────┴────┬─────────┐
Таблица    Пуш       Почта
```

Три канала работают независимо. Настроить можно любое количество — что
настроено, то и сработает. Упал один, остальные всё равно доставят.

Покупатель в любом случае видит «Заказ принят» — заказ уже у тебя, даже если
почта в этот момент лежит.

**Сейчас не настроено ничего.** Заказ пишется только в окно командной строки,
где запущен сервер. Закрыл окно — заказ пропал. Поэтому дальше по шагам.

---

## Сначала самое важное

Заявки приходят, только когда сайт где-то работает.

Пока ты запускаешь его командой `npm run dev` у себя на компьютере, сайт живёт
по адресу `localhost:3000` и виден только тебе. Выключил компьютер — сайта нет,
и заказать никто не может.

Чтобы сайт работал круглосуточно, его надо выложить. Бесплатный вариант —
**Vercel**: заливаешь проект, получаешь адрес вида `futbolki.vercel.app`,
дальше он работает сам. Это отдельный разговор, скажи — распишу.

Настраивать каналы можно уже сейчас: на локальном сайте они точно так же
работают, и можно всё проверить на тестовом заказе.

---

## Что нужно скачать

**Только одно приложение — ntfy, на телефон.** Оно даёт мгновенное
уведомление о заказе. Всё остальное настраивается в браузере, качать нечего.

| Канал | Что качать | Сколько времени |
|---|---|---|
| Google Таблица | ничего | 10 минут |
| Пуш на телефон | приложение ntfy | 3 минуты |
| Почта | ничего | 2 минуты |

На компьютере ничего дополнительно ставить не надо.

## Шаг 0. Создать файл настроек

В корне проекта, рядом с `package.json`, создай файл с именем **`.env.local`**
— именно так, с точкой в начале и без расширения `.txt`.

Проще всего: открой папку проекта в редакторе кода и создай файл там.
Через проводник Windows тоже можно, но он любит дописать `.txt` — проверь, что
имя получилось ровно `.env.local`.

Файл пока пустой. В него будем дописывать строки.

Этот файл специально в `.gitignore` — ключи из него никогда не попадут в
репозиторий и не утекут.

---

## Шаг 1. Google Таблица — основное хранилище

Каждый заказ падает новой строкой: дата, имя, телефон, страна, адрес, состав,
сумма. Получается таблица, которую можно сортировать, фильтровать и считать
выручку.

Это главный канал. Пуш и почта — чтобы узнать быстро, а хранится всё здесь.

1. Создай новую Google Таблицу

2. В первую строку впиши заголовки, каждый в свою ячейку:

   `дата` · `имя` · `телефон` · `страна` · `адрес` · `комментарий` ·
   `товары` · `сумма ₽` · `показано` · `валюта` · `язык`

3. Меню **Расширения → Apps Script**

4. Удали всё, что там написано, и вставь это:

```js
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const d = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(), d.name, d.phone, d.country, d.city,
    d.comment, d.items, d.totalRub, d.shown, d.currency, d.lang
  ]);
  return ContentService.createTextOutput("ok");
}
```

5. Сохрани (значок дискеты)

6. **Развернуть → Новое развёртывание**. Тип — **Веб-приложение**

7. «Выполнять от имени» — **от своего имени**.
   «У кого есть доступ» — **все**

8. Google попросит разрешение — согласись. Он покажет страшное окно
   «приложение не проверено»: жми **Дополнительные настройки → Перейти к
   проекту**. Это твой собственный скрипт, всё нормально

9. Скопируй выданную ссылку и впиши в `.env.local`:

```
GOOGLE_SHEET_URL=https://script.google.com/macros/s/ВАША_ССЫЛКА/exec
```

**Эту ссылку никому не показывай.** Кто её знает, тот может дописывать строки
в твою таблицу. Она нужна только серверу, в браузере покупателя её не видно.

## Шаг 2. Пуш на телефон — чтобы узнать сразу

Сервис ntfy: бесплатный, без регистрации, уведомление приходит за секунды.

1. Поставь приложение **ntfy** — есть в RuStore, Google Play и App Store

2. Придумай название темы. Это одновременно и адрес, и пароль: **кто знает
   название, тот видит твои заказы.** Поэтому не `zakazy`, а что-то вроде
   `futbolki-russia-zakazy-8x3k7q`

3. В приложении нажми плюс, введи это название, подпишись

4. Впиши в `.env.local`:

```
NTFY_TOPIC=futbolki-russia-zakazy-8x3k7q
```

Проверить можно прямо в браузере: открой `https://ntfy.sh/твоя-тема` —
увидишь все уведомления, которые туда приходили.

## Шаг 3. Почта — запасной канал

Через Web3Forms. Бесплатно, нужен только публичный ключ.
**Пароль от почты нигде не вводится** — сервис отправляет письма сам.

1. Зайди на [web3forms.com](https://web3forms.com)

2. Введи почту `89282181871rrg@gmail.com`, нажми кнопку получения ключа

3. Ключ придёт письмом. Скопируй его и впиши в `.env.local`:

```
WEB3FORMS_KEY=твой-ключ
```

## Как выглядит готовый файл

```
GOOGLE_SHEET_URL=https://script.google.com/macros/s/AKfy.../exec
NTFY_TOPIC=futbolki-russia-zakazy-8x3k7q
WEB3FORMS_KEY=abcd1234-5678-...
```

Строки, которые не нужны, можно просто не писать.

**После создания или изменения файла обязательно перезапусти сервер:**
в окне командной строки нажми `Ctrl+C`, потом снова `npm run dev`.
Настройки читаются один раз при старте, на лету не подхватываются.

## Как проверить, что работает

Открой сайт, положи товар в корзину, заполни форму, отправь.

В окне командной строки появится строка:

```
[заказ] Доставлен: { таблица: 'ок', пуш: 'ок', почта: 'не настроен' }
```

Что означают ответы:

- `ок` — канал сработал, заказ доставлен
- `не настроен` — этой строки нет в `.env.local`
- `ошибка 401`, `ошибка 403` — ключ или ссылка неверные
- `сбой` — не было связи с интернетом

Если ни один канал не сработал, в консоль выведется весь заказ целиком —
чтобы ты мог хотя бы переписать его руками.

## На боевом сайте

Когда выложишь проект на Vercel, файл `.env.local` туда **не поедет** — он в
`.gitignore`, и это правильно.

Те же три строки надо вписать в настройках проекта:
**Settings → Environment Variables**. После этого нажать **Redeploy**.
