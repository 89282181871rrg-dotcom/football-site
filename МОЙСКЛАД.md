# МойСклад → каталог сайта

Сайт сам берёт из МойСклада товары, цены, размеры, остатки и фото.
Обновление — раз в 5 минут, ничего нажимать не надо.

## Как вести товары в МойСкладе

| В МойСкладе | На сайте |
|---|---|
| Название товара | Название карточки |
| Первая строка описания | Подпись под названием |
| Цена продажи (первая) | Цена |
| Фото товара | Фото карточки и галерея (первое — главное) |
| Группа товара | Категория: «Шиповки», «Бутсы», «Сороконожки», «Перчатки», «Мячи», «Детям» — по словам в названии группы |
| Модификации с характеристикой «Размер» | Размеры |
| Остатки | Показываются только размеры в наличии |

Товар **не попадёт** на сайт, если: он в архиве, у него нет фото, нет цены,
или ни одного размера нет в наличии.

## Подключение (один раз)

1. МойСклад → шестерёнка «Настройки» → **Токены** → **Создать токен**.
   Лучше завести отдельного пользователя только с правом просмотра товаров и остатков.
2. Vercel → проект → Settings → Environment Variables → добавить
   `MOYSKLAD_TOKEN` = токен.
3. Сделать redeploy.

Товары добавляются только через МойСклад. Пока токена нет или МойСклад
недоступен — каталог на сайте пустой.

## Настройки (необязательно)

- `MOYSKLAD_SIZE_ATTR` — если характеристика размера называется не «Размер».
