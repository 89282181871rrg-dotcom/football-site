# Языки и валюты

## Что работает сейчас

Девять языков: русский, английский, немецкий, испанский, французский,
итальянский, португальский, турецкий, арабский.

Язык угадывается по браузеру. Немец увидит немецкий и евро, турок — турецкий
и лиру, все остальные — английский. Выбор из переключателя в шапке
запоминается и переживает перезагрузку.

Русский и английский зашиты в сборку. Остальные подгружаются только когда их
выбрали, поэтому посетитель не качает девять словарей ради одного.

---

## Где лежат тексты

Один файл на язык: `lib/locales/ru.js`, `en.js`, `de.js` и так далее.

Внутри три части:

- `ui` — весь интерфейс, 99 строк
- `faq` — шесть вопросов и ответов
- `phrases` — описания товаров

**Русский файл — источник правды.** Если в другом языке строку забыли, сайт
подставит английскую, а если и её нет — русскую. Пустых мест не бывает.

### Как поменять текст

Найти строку по смыслу в `ru.js`, поправить справа от двоеточия. **Слева
менять нельзя** — это ключ, по нему ищется перевод во всех остальных языках.
Потом то же самое в тех языках, где текст должен измениться.

### Описания товаров

В `lib/products.js` они написаны по-русски, и русская строка работает ключом.
Например `subtitle: "Бутсы · классика"` — эта же строка ищется в `phrases`
каждого языка.

Добавили товар с новым описанием — допишите его в `phrases` всех девяти
файлов. Не допишете, ничего не сломается: иностранец увидит русский текст.

## Запасные языки

В `lib/locales/extra` лежат готовые переводы: нидерландский, польский,
чешский, украинский, сербский, румынский, греческий, шведский, венгерский,
иврит, персидский, хинди.

Они переведены целиком, просто не подключены — чтобы сайт оставался лёгким.

### Как включить, три шага

1. Перенести файл из `lib/locales/extra` в `lib/locales`
2. В `lib/i18n.js` добавить строку в `LANGUAGES`:

```js
pl: { code: "pl", label: "Polski", short: "PL", search: "polish польский" },
```

3. Там же добавить строку в `LOADERS`:

```js
pl: () => import("./locales/pl"),
```

Для иврита и персидского добавить код ещё и в `RTL` — они пишутся справа
налево:

```js
export const RTL = new Set(["ar", "he", "fa"]);
```

Перезапустить сервер. Всё.

## Валюты

44 валюты, курс тянется у Центробанка раз в 12 часов. Базовая цена всегда в
рублях, в `lib/products.js` — остальное считается на лету. Менять цены
по-прежнему в одном месте.

Цена округляется до понятного шага: доллары до единиц, тенге до сотен, донги
до десяти тысяч. Никаких «62.87».

**Важно.** Добавлять можно только валюты, которые есть у Центробанка. Если
валюты там нет, курс замрёт на запасном значении из `lib/currency.js` и цены
поедут. Каких валют не хватило, видно в окне сервера при первом запросе курса.

Если курс не подтянулся совсем — работают запасные значения, а покупателю
показывается честная строка: итоговая сумма подтверждается при заказе.

## Чего сайт не переводит

Заголовок вкладки и описание для поиска. Страница на сайте одна, а Next умеет
менять их только по адресу — для этого нужны отдельные адреса вида `/en`,
`/de`. Пока они написаны сразу на русском и английском, этого хватает.
