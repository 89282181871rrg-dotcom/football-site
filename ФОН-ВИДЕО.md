# Как поменять видео на фоне

## Коротко

Два шага, минута времени.

**1. Положи файл** в папку `public\video\`

**2. Открой** `components\VideoBackground.jsx` (Блокнотом или VS Code) и поменяй строку 11:

```js
const SRC = "/video/имя-твоего-файла.mp4";
```

Сохрани (Ctrl+S) и обнови страницу в браузере. Пересобирать ничего не нужно.

---

## Про путь — здесь чаще всего ошибаются

Правильно:
```js
const SRC = "/video/football.mp4";
```

Неправильно:
```js
const SRC = "football";                        // нет папки и расширения
const SRC = "public/video/football.mp4";       // слово public писать не надо
const SRC = "C:\video\football.mp4";           // путь с диска не подходит
const SRC = "video/football.mp4";              // забыт слэш в начале
```

Три обязательные части: **слэш в начале**, **`video/`**, **расширение файла**.

Слово `public` в адресе не пишется никогда — браузер видит содержимое этой
папки как корень сайта.

## Настройки рядом, в том же файле

```js
const OVERLAY = 0.2;   // затемнение поверх видео
const ZOOM = 1.25;        // увеличение кадра на компьютере
const ZOOM_TABLET = 1.1;  // на планшете
const ZOOM_PHONE = 1;     // на телефоне
```

**OVERLAY** — насколько гасим видео. Меньше число — фон ярче, но текст хуже
читается. Ниже 0.15 заголовок в герое начнёт теряться на светлых кадрах.
Больше 0.5 — видео превратится в еле заметную текстуру.

**ZOOM** — увеличение, и значений три, по одному на размер экрана.

Так сделано потому, что телефон держат вертикально, а ролик горизонтальный.
Браузер вписывает кадр по высоте, и на экране остаётся узкая полоса из середины
кадра — около четверти ширины. Увеличивать её ещё сильнее нечего: фон
превращается в пятно. Поэтому на телефоне 1, на планшете 1.1, на компьютере 1.25.

Сам выбор по ширине экрана лежит в `app/globals.css`, правило `.bg-video`.
Менять там ничего не надо — только числа в компоненте.

Дальше про увеличение вообще. Нужно, если в ролике есть чёрные поля по краям: при 1.25
обрезается по 12% с каждой стороны и поля уходят за экран. Если полей нет,
ставь 1 — картинка будет чётче.

## Требования к файлу

**Формат:** MP4 с кодеком H.264. Это то, что понимают все браузеры.
Если видео из редактора не проигрывается — почти всегда дело в экзотическом
кодеке (H.265/HEVC, ProRes). Пересохрани в обычный H.264.

**Вес:** ориентир до 1–2 МБ. Фон грузится при каждом заходе на сайт.
11 МБ на мобильном интернете догружаются секунд девять — страница работает,
но фон появится не сразу.

**Длина:** 10–15 секунд достаточно. Петля повторяется, зритель смотрит
на товар, а не на фон. Короче ролик — меньше вес.

**Разрешение:** 720p с запасом. Фон затемнён и не в фокусе, разницы
с 1080p не видно, а вес вдвое меньше.

**Звук:** удалить. Он всё равно выключен, но занимает место в файле.

## Если склеиваешь несколько роликов

Куски должны быть одного разрешения. Иначе редактор вписывает меньший в кадр
и дорисовывает чёрные поля — на сайте они будут видны, и убрать их можно
только увеличением ZOOM, что портит остальные сцены.

При добавлении клипа выбирай режим **«Заполнить кадр»** (Fill, Crop to Fill),
а не **«Вписать»** (Fit, Contain).

## Что делать, если фон не появился

**Проверь файл напрямую.** Вставь в адресную строку браузера:

```
http://localhost:3000/video/имя-твоего-файла.mp4
```

- Играет — файл в порядке, ищи ошибку в пути внутри `SRC`
- Чёрный экран — браузер не понимает кодек, пересохрани в H.264
- Страница 404 — файла нет по этому адресу, проверь имя посимвольно

**Посмотри консоль.** F12 → вкладка Console. Если видео не загрузилось,
там будет строка `[фон] Видео не загрузилось:` с путём.

**Проверь, что файл не пустой.** Открой его двойным кликом обычным плеером
прямо из папки `public\video\`. Бывает, что копирование обрывается: размер
правильный, а внутри одни нули. Проводник такое не показывает.

**Перезапусти сервер.** Ctrl+C в окне командной строки, потом `npm run dev`.
Next.js иногда не замечает файлы, добавленные в `public` при работающем сервере.

## Вернуть анимированный фон вместо видео

Компонент `SiteBackground.jsx` рисует тёмную сцену с частицами прямо в браузере —
он никуда не делся. Чтобы вернуть его, в `app\layout.jsx` поменяй две строки:

```js
import SiteBackground from "@/components/SiteBackground";
...
<SiteBackground />
```

Весит ноль килобайт, работает везде, не зависит от кодеков.

---

## Про чужие видео

Ролики из трансляций, заставки лиг и клубов, чужие рекламные видео —
на боевом сайте использовать нельзя. Там и авторские права на саму работу,
и товарные знаки клубов и вещателей. Обычный итог — не суд, а жалоба хостингу
и снятый сайт в самый неподходящий момент.

Что можно брать свободно: стоковые ролики с коммерческой лицензией
(Pexels, Coverr, Mixkit) и собственную съёмку.
