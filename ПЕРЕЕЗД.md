# Переезд на свой сервер в России (Timeweb Cloud)

Зачем: Vercel в России заблокирован, сайт открывается нестабильно даже с VPN.
Сервер в Москве открывается у всех — и с VPN, и без.

## Что заказать

Timeweb Cloud → Облачные серверы → Создать:
- Локация: **Москва**
- Образ: **Ubuntu 24.04**
- Тариф: самый дешёвый (1 CPU, 1 ГБ RAM, ~15 ГБ диска)
- SSH-ключ можно не добавлять — пароль root придёт на почту

## Установка (делает разработчик)

```
ssh root@IP_СЕРВЕРА
curl -fsSL https://raw.githubusercontent.com/89282181871rrg-dotcom/football-site/master/deploy/setup.sh -o setup.sh
bash setup.sh
nano /opt/futbolki/.env.local     # вписать MOYSKLAD_TOKEN=...
bash /opt/futbolki/deploy/update.sh --force
```

Проверить сайт по адресу `http://IP_СЕРВЕРА` — с VPN и без.

## Переключение домена (после проверки)

1. hosting.timeweb.ru → Домены → futbolki-russia.ru → Редактор DNS:
   записи A для `@` и `www` → IP сервера.
2. На сервере: `bash setup.sh futbolki-russia.ru` — Caddy сам выпустит https.

## Дальше

- Сайт сам обновляется из GitHub каждые 5 минут.
- Товары — как раньше, из МойСклада.
- Логи обновлений: `/var/log/futbolki-update.log`, сайта: `journalctl -u futbolki`.
