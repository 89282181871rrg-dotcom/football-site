# Как запустить сайт и посмотреть

## Шаг 1. Поставить Node.js (один раз)

Скачать с [nodejs.org](https://nodejs.org) версию **LTS** и установить, всё время нажимая «Далее».

Проверить, что встало: открыть командную строку и набрать

```
node -v
```

Должна появиться версия вида `v22.x.x`. Если пишет «не является внутренней командой» — перезагрузить компьютер.

## Шаг 2. Открыть командную строку в папке проекта

Самый простой способ: открыть папку `сайт футболки раша` в проводнике, кликнуть в **адресную строку** сверху, стереть путь, написать `cmd` и нажать Enter.

Откроется чёрное окно, уже находящееся в нужной папке.

## Шаг 3. Установить зависимости (один раз)

```
npm install
```

Скачает около 300 МБ, займёт 1–3 минуты. Ругань про `deprecated` и `warn` — нормально, это не ошибки.

## Шаг 4. Запустить

```
npm run dev
```

Когда появится строка `Ready in ... ms` — открыть в браузере:

**http://localhost:3000**

Сайт работает, пока окно с командной строкой открыто. Правки в коде подхватываются сами, страницу перезагружать не нужно.

**Остановить:** нажать `Ctrl + C` в этом окне.

## Посмотреть на телефоне

Полезно — половина покупателей придёт с телефона.

1. Узнать IP компьютера: в командной строке набрать `ipconfig`, найти строку «IPv4-адрес», например `192.168.1.42`
2. Запустить с доступом по сети:

```
npm run dev -- -H 0.0.0.0
```

3. На телефоне (в той же Wi-Fi сети) открыть `http://192.168.1.42:3000`

Если не открывается — обычно мешает брандмауэр Windows, при первом запуске он спросит разрешение, нужно нажать «Разрешить доступ».

## Если что-то пошло не так

**`npm` не является внутренней командой** — Node.js не установлен или нужна перезагрузка.

**`EADDRINUSE: port 3000`** — порт занят другим процессом. Запустить на другом порту:
```
npm run dev -- -p 3001
```

**Ошибки при `npm install`** — удалить папку `node_modules` и файл `package-lock.json`, повторить.

**Любая другая ошибка** — скопировать текст ошибки целиком и прислать мне.
