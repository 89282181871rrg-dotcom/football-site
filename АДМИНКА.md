# Админка — хозяин добавляет товары сам

Теперь при новом товаре не нужно писать разработчику. Хозяин заходит на
`адрес-сайта/admin`, заполняет форму, фото, и товар сразу появляется в
каталоге на сайте.

**Важно понимать сразу.** Те 27 товаров, что уже на сайте, через админку не
редактируются и не удаляются — их по-прежнему меняет разработчик в коде. Так
безопаснее: у них есть переводы на девять языков, и менять текст напрямую
означало бы либо ломать перевод, либо переписывать его на всех языках при
каждой правке. Товары, добавленные через админку, показываются на всех
языках сайта, но их описание — только на русском.

---

## Шаг 1. Подключить хранилище фото

Без этого шага админка работать не будет — фото и список новых товаров
хранить негде.

1. Зайди в проект на [vercel.com](https://vercel.com)
2. Открой вкладку **Storage**
3. **Create Database → Blob**
4. Название любое, например `futbolki-photos`
5. Нажми **Connect to Project**, выбери свой проект

Готово. Vercel сам добавит нужный ключ (`BLOB_READ_WRITE_TOKEN`) в настройки
проекта — вписывать его вручную никуда не надо.

---

## Шаг 2. Задать пароль

1. В проекте на Vercel: **Settings → Environment Variables**
2. Добавь строку:

```
ADMIN_PASSWORD=твой-пароль
```

Пароль придумай сам, любой, но не совсем простой — от него зависит, кто
может добавлять и удалять товары на сайте.

3. После добавления нажми **Redeploy**, чтобы изменения применились

---

## Шаг 3. Пользоваться

Открой `адрес-сайта/admin` — например `https://football-site-mu.vercel.app/admin`.

Спросит пароль — тот, что задали в шаге 2.

Дальше форма:

- **Название** — например «Nike Phantom»
- **Подпись** — коротко под названием, например «Шиповки · новая расцветка».
  Необязательно
- **Категория** — из тех же шести разделов, что и на сайте
- **Цена** — в рублях, остальные валюты сайт посчитает сам
- **Пометка на фото** — «Хит», «Топ», «1+1» и так далее. Необязательно
- **Комментарий под ценой** — например «Маломерит, берите на размер больше».
  Необязательно
- **Размеры** — нажимаешь на нужные. Если товар без размера (мяч, боди),
  ставишь галочку «У товара нет размеров»
- **Фотографии** — можно сразу несколько, первая станет главной на карточке

Нажимаешь «Добавить товар» — он в ту же секунду появляется на сайте.

Ниже формы — список уже добавленного, с кнопкой «Удалить» у каждого.

**Про размер фото.** Дальше сайт возьмёт то, что загрузили, как есть.
Для аккуратной карточки годится любое нормальное фото с телефона — сайт сам
подгонит его под рамку. Слишком большие файлы просто дольше загружаются
у покупателя, поэтому лучше не грузить фото весом в десятки мегабайт.

## Локальная разработка (для разработчика)

Чтобы админка работала на компьютере при `npm run dev`, нужно:

1. Установить пакет: `npm install`
2. В `.env.local` вписать:

```
ADMIN_PASSWORD=любой-пароль-для-теста
```

3. Токен `BLOB_READ_WRITE_TOKEN` для локальной работы: Vercel → Storage →
   Blob → вкладка `.env.local` → скопировать готовую строку целиком

Без токена сайт всё равно откроется и будет работать — просто раздел
«добавлено через админку» будет пустым, а сохранение фото выдаст ошибку.
Витрина от этого не ломается, это сделано намеренно.
